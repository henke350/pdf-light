# Rust skills (vendored)

These skill folders are copied from https://github.com/actionbook/rust-skills
(commit 5c40d3a, MIT licence), "skills-only" mode as that project's README recommends.

Copied: coding-guidelines, m01–m07, m09–m15, unsafe-checker, rust-router.

Left out on purpose:
- the plugin's `UserPromptSubmit` hook and its `actionbook` MCP server (`npx @actionbookdev/mcp@latest`);
- skills that drive outside tools or services (core-*, rust-daily, rust-learner, rust-skill-creator);
- domain skills that don't apply to a desktop PDF app (domain-web, -fintech, -iot, -ml, -embedded,
  -cloud-native, -cli) and the LSP-tool skills.

`rust-best-practices/` is copied from https://github.com/apollographql/skills
(commit 9dda139, MIT licence, see `rust-best-practices/LICENSE`), based on Apollo's
Rust Best Practices Handbook.
